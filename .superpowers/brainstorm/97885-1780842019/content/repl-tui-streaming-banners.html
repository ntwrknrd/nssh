Transcript-first TUI with live banner blocks

Completed devices append immediately in completion order. The status line keeps slow or pending devices visible.

Preview: nssh repl TUI
nssh repl concurrency 12
@acm-lab-agg-sw(1,2,3) show hostname
---------------- acm-lab-agg-sw2.custcbb.local | show hostname ----------------
Hostname: acm-lab-agg-sw2
FQDN: acm-lab-agg-sw2.custcbb.local
---------------- acm-lab-agg-sw1.custcbb.local | show hostname ----------------
Hostname: acm-lab-agg-sw1
FQDN: acm-lab-agg-sw1.custcbb.local
waiting: acm-lab-agg-sw3.custcbb.local
running 1/3 done 2/3 failed 0/3 active: acm-lab-agg-sw3.custcbb.local
nssh> @select:group:local/lab show interfaces status

Behavior locked in

  • Print each device block as soon as that device completes.
  • Use the existing REPL banner style for every output block.
  • Keep the bottom prompt and running status visible.

Tradeoff

  • Output order becomes completion order, not target order.
  • A slow device only delays its own banner block, not the whole batch.
