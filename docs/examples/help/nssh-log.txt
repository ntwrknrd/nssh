╭────────────────────────────────────────────────╮
│ nssh log                                       │
│ Inspect, play, and manage nssh recording files │
╰────────────────────────────────────────────────╯

Commands:
  nssh log list [OPTIONS]
    List recorded sessions                                                      
  nssh log play [OPTIONS]
    Play a recorded session                                                     
  nssh log upload [OPTIONS]
    Upload recording to asciinema server                                        
  nssh log export [OPTIONS]
    Export to text or GIF format                                                
  nssh log cleanup [OPTIONS]
    Remove old recordings                                                       

Options:
  --file FILE, -f
    Path to recording file                                                      
  --date YYYY-MM-DD
    Filter by date                                                              
  --search TERM, -s
    Filter by keyword                                                           
  --output FILE, -o
    Output path for export                                                      
  --format txt|gif
    Export format (default: txt)                                                
  --dry-run
    Preview without executing
